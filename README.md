# הלומדות שלי

אתר סטטי (HTML/JS בלבד, בלי שרת ובלי build) שמרכז לומדות לילדים לפי נושא וגיל. מתאים לפרסום ב-GitHub Pages.

## מבנה

```
index.html                     מסך הבית: קטלוג עם סינון לפי גיל ונושא
apps/catalog.js                רשימת הלומדות והנושאים
apps/<id>/index.html           כל לומדה בתיקייה משלה
```

## איך מוסיפים לומדה חדשה

1. יוצרים תיקייה `apps/<id>/` ושמים בה `index.html` של הלומדה.
2. מוסיפים רשומה ל-`LUMDA_APPS` ב-`apps/catalog.js`: `id`, `title`, `description`, `subject`, `ages: [מגיל, עד גיל]`, `icon`, `path`.
3. נושא חדש מוסיפים ל-`LUMDA_SUBJECTS` באותו קובץ.
4. בתוך הלומדה, קישור חזרה למסך הבית הוא `../../index.html`.

כל לומדה שומרת התקדמות ב-localStorage עם מפתחות בקידומת משלה (למשל `melody-`), כדי שלא יתנגשו.

## פינת ההורים (melody-english)

לוחצים לחיצה ארוכה (2 שניות) על הכותרת למעלה. שם רואים התקדמות ומילים לתרגול, מכבים או מאטים את הדיבור, שומרים ומשחזרים גיבוי לקובץ, ומאפסים התקדמות.
אפשר גם לכבות את התרגום לעברית בכרטיסי המילים, לכבות את המיקרופון במשחק Say it! (הזיהוי נעשה בשרתים של גוגל), ולקבוע תזכורת להפסקה אחרי 15, 20 או 30 דקות.

## הנושאים והמשחקים (melody-english)

19 נושאים, ביניהם אותיות ABC (כל אות עם מילה מוכרת), פעלים, רגשות ומשפטים קצרים. כל נושא מחולק לשלבים של כ-5 מילים.
המשחקים בכל שלב: Find it, Balloons, Memory, What's this? (שומעים שתי מילים ובוחרים את זו שמתאימה לתמונה) ו-Say it! (אומרים את המילה והטלפון מקשיב). בצבעים יש גם Magic Dress / Magic Armor, ובפעלים יש Do it! (עושים את הפעולה עם הגוף).
בכל נושא יש גם Echo (שומעים מילה וחוזרים עליה, והפרח גדל או הדרקון מתעורר). בגוף יש Simon says, בבגדים Dress up (מלבישים את הדובי לפי צבע ובגד), ובפירות ובאוכל יש Shop ("Give me three apples"). במסך המשחקים מודגש משחק שונה מהאחרון ששיחקו.
בעמוד המפתח אפשר להפעיל כל משחק בכל נושא, עם כל המילים ובלי לשנות התקדמות.
המשחקים החדשים נפתחים בהדרגה לפי מספר השלבים שהושלמו (Echo אחרי 2, Simon says אחרי 3, Dress up אחרי 4, Shop אחרי 5). אחרי שמקבלים כתר בנושא מופיע Challenge: שש שאלות מכל הנושא, ובסופן כתר זהב. מדי פעם תשובה נכונה שווה כוכב זהב (שני כוכבים), ובמסך הסיום מוצע משחק אחר במקום Again.

## הילדים (kids.js)

מסך הבית מתחיל ב"מי משחק היום?". לוחצים על הדמות, שומעים ברכה ("ברוכה הבאה מלודי" או "ברוך הבא ים"), ואז מופיעות הלומדות של אותו ילד לפי השדה `kids` ב-`apps/catalog.js`.
הילד שנבחר נשמר ב-localStorage במפתח `lumda-kid`. כל לומדה יכולה לקרוא אותו עם `LUMDA_KID()` (מ-`../../kids.js`) ולהתאים שם, לשון פנייה, קול ודמות. הדמויות נמצאות ב-`assets/kids/`.
